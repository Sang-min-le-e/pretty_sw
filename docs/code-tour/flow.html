2. 데이터가 흐르는 층

화면ConsumerWidget
ref.watch / read
provider데이터를 꺼내는 손잡이
*Provider, *Actions
저장소읽기·쓰기 약속
*Repository
도구ApiClient(Dio)
LocalStorageService
데이터가 사는 곳서버(백엔드) · 기기 안 Hive

서버에 있는 것: 로그인, 내 정보(이름), 자녀 등록. 기기 안(Hive)에만 있는 것: 루틴, 템플릿, 연결된 기기, 프로필 사진 경로, 로그인 세션(accessUuid). 쓰기가 끝나면 ref.invalidate(목록Provider)로 낡은 캐시를 버려 화면이 새로 그려집니다.
