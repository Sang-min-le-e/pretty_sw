# routine_app (Tomo)

지적장애인 자녀를 둔 보호자를 위한 루틴 관리 앱. Flutter + Riverpod + go_router + Hive.

Figma 디자인(파일 "예소")을 기준으로 화면을 구현하고 있으며, 진행 상황은 아래 빌드 노트에 정리한다.

## 빌드 노트

개발할 때마다 갱신하는 세션 정리 문서. 그날 구현한 화면(Figma 노드 번호 포함), 화면 흐름 다이어그램, 발견·수정한 버그, 프로젝트 폴더 구조를 한 페이지에서 볼 수 있다.

**https://claude.ai/code/artifact/133d6133-864f-4e1e-ab96-ef79d60f26b5**

- 링크는 고정이며, 개발 세션마다 같은 페이지를 새 내용으로 갱신한다.
- 비공개 상태 — 공유하려면 페이지의 공유 메뉴에서 설정을 바꾼다.
